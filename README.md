# 线上补习点名 + 收费提醒系统

用 Google Sheet + Apps Script 做的补习管理系统。点名、算堂数、到期提醒缴费,一张试算表搞定。

**设计前提(已跟使用者确认):**

| 项目 | 决定 |
|---|---|
| 上课形式 | **小组班**,依班级点名(实际使用者有 4 个班、约 40 位学生) |
| 计费规则 | 排课就算,**学生自己不来照扣**;生病/比赛可由老师标「请假(免扣)」 |
| 通知方式 | 系统只**生成草稿 + WhatsApp 链接**,不自动送出 |
| 使用者 | 单人使用(老师本人),不需要登入系统 |
| 形态 | Google Sheet + Apps Script |

已经在用 Excel 点名的话,先看 [**九、从旧 Excel 汇入**](#九从旧-excel-汇入)。

## 一、安装(约 3 分钟,只做一次)

> **这不是网站,没有网址。** 它是跑在你自己 Google 帐号里的一张 Google Sheet,
> 资料只存在你的 Google Drive,不经过任何第三方伺服器。

1. 打开 [sheets.new](https://sheets.new) 建一个新的 Google Sheet,取名例如「补习管理」。
2. 选单:**扩充功能 (Extensions) → Apps Script**。
3. 打开 **[`apps-script/ALL-IN-ONE.gs`](apps-script/ALL-IN-ONE.gs)**,全选复制,
   贴到 Apps Script 编辑器里(先把预设的 `function myFunction() {}` 那几行删掉)。
4. 按 **储存 (💾)**。
5. 回到试算表,**重新整理页面**(F5)。上方会出现新选单 **📚 补习管理**。
6. 点 **📚 补习管理 → 🔧 初始化 / 修复表格**。第一次会跳授权画面:
   `检阅权限 → 选你的 Google 帐号 → 进阶 → 前往「未验证的应用程式」→ 允许`。
   (这是你自己贴的脚本、跑在你自己的档案里,Google 对未上架的脚本一律这样提示。)
7. 看到 ✅ 初始化完成 就好了。

> **想先玩玩看再认真用?** 就照上面做一次,随便加两个假学生点几次名,
> 看看总览会不会变红。玩坏了不用怕 —— 重新开一个空白 Sheet 再贴一次就好。

> 时区预设 `Asia/Kuala_Lumpur`。要改的话到 Apps Script 的 ⚙️ 专案设定。

### 更新到新版程式码

1. Apps Script 里 **Ctrl+A 全选 → 删除**,重新贴上新的 `ALL-IN-ONE.gs`
2. 储存
3. 执行 **`setupWorkbook`**(选单是 `🔧 初始化 / 修复表格`)

## 二、先填两个地方

### 「设置」表

| 设定项目 | 说明 |
|---|---|
| 老师名字 | 讯息的署名 |
| 每期配套堂数 | 一期几堂,预设 `4`(就是你说的「补了4次」) |
| 默认每堂收费RM | 学生表没个别填收费时用这个 |
| 催费门槛(余额≤) | 预设 `0` —— 堂数用完就标红 |
| 预告门槛(余额=) | 预设 `1` —— 剩最后一堂先温馨提示 |
| 催费讯息模板 | 可用变数:`{家长} {学生} {老师} {已扣堂数} {余额} {配套堂数} {金额} {每堂收费}` |
| 预告讯息模板 | 同上 |

### 「学生」表

打上**姓名**,系统会自动配 `学生ID`(S001…)和状态「在读」。其余填一填:

| 栏位 | 备注 |
|---|---|
| **班级** | 例如 `初二科学`、`高三`。**点名是按班级载入的,这栏一定要填** |
| 家长称呼 | 讯息开头会用,例如「陈太太」。留空就用「XXX家长」 |
| WhatsApp号码 | `0123456789` 或 `60123456789` 都可以,系统会自动转成 wa.me 格式 |
| 每堂收费RM / 配套堂数 | 留空就用「设置」的预设值(可以每个学生不一样) |
| 状态 | `在读` / `暂停` / `结束`。结束的不会出现在总览和点名表 |

班级不用另外维护清单 —— 你在学生表打什么,点名的班级下拉就会出现什么。

## 三、日常操作

### 点名(每堂课后 10 秒)

到「今日点名」表,先设好最上面那两格:

- **B1 = 上课日期**(空白的话载入时会自动填今天)
- **D1 = 班级**(下拉选,内容来自学生表)

然后:

```
📚 补习管理 → ✅ 载入今日点名
```

只会载入**那一班**的在读学生,**预设全部「出席」**,并显示每个人的
**目前余额**和**欠款RM**(有欠款的整格标红,当场就能开口跟学生讲)。
你只需要改有状况的那几个,然后:

```
📚 补习管理 → 📥 提交点名
```

提交后系统立刻告诉你:记了几笔、扣几堂、**以及谁的堂数已经用完该催费了**。

> **一天有两个班?** 点完一班,把 D1 换成另一班,再载入一次就好。
> **要补录前几天的课?** 把 B1 的日期改掉再载入。
> 同一个学生同一天只会记一笔,重复提交会自动略过。

### 出席状态的规则

| 状态 | 扣堂? | 什么时候用 |
|---|---|---|
| 出席 | ✅ 扣 | 正常上课 |
| 缺席(照算) | ✅ 扣 | 学生自己没来、没提前讲 |
| 请假(免扣) | ❌ 不扣 | 生病、比赛,你批准的 |
| 我取消(免扣) | ❌ 不扣 | 你自己取消的 |
| 公假/停课(免扣) | ❌ 不扣 | 公共假期、考试周 |

规则写在 `00_Config.gs` 的 `CHARGEABLE_BY_STATUS`,要改哪一个算不算钱,改那里就好。

### 记录收款

```
📚 补习管理 → 💵 记录收款
```

跳出视窗,四步搞定:

1. **选班级** → 学生清单只剩那一班(留空 = 全部)
2. **选学生** → 名字后面直接标着 `⚠️ 欠 11 堂`,而且欠最多的排最前面
3. 堂数和金额**自动带好**(该学生的配套 × 他自己的每堂收费),要改就改
4. 选收款方式和日期 → 按 **记录收款**

送出后**视窗不关**,余额立刻重算,下面会累积这次记了哪几笔 ——
一堂课跟好几个学生收钱时可以连续记完。

> 也可以直接到「付款记录」表手打一行:**学生ID、金额RM、购买堂数**,
> 姓名和时间戳会自动带出来。视窗只是比较不容易打错。

> 学生付 4 堂的钱 → `购买堂数 = 4`。付 8 堂 → 填 8。系统照样运作,不必改设定。

### 看谁欠钱、欠多少

**「总览」分页**就是答案。依 班级 → 余额 排序,快没堂数的排在每个班的最上面:

| 栏位 | 意思 |
|---|---|
| 余额 | 还剩几堂。**负数 = 欠几堂**(红色粗体) |
| **欠款RM** | 欠的堂数 × 该学生的每堂收费(不同班收费不同,会各自算) |
| 提醒状态 | 🔴 该催费 / 🟡 快用完 / 🟢 正常 |
| 上次上课 | 太久没出现的可以顺便留意 |

每次 `🔄 刷新总览`,右下角会跳出总计:

```
总览已更新:40 位学生 · 4 个班 · 🔴 38 位该催费,共欠 RM5350.00
```

只想看该催的那几个,用 `📱 查看催费草稿` —— 只列 🔴 和 🟡,**欠最多的排最前面**。

### 催费

```
📚 补习管理 → 📱 查看催费草稿
```

会跳出视窗,列出所有 🔴 该催费 和 🟡 快用完 的学生,连讯息文案都写好了。
按 **📱 在 WhatsApp 打开** → WhatsApp 会带着文字开起来 → **你再决定要不要送**。

送出后回「总览」勾一下 **已发送**,系统会写进「催费日志」,勾勾会自动跳回(下一期还能再勾)。

「总览」每一行右边也有一颗 📱 发送催费 链接,效果一样。

## 四、余额是怎么算的

```
余额 = 已付堂数 − 已扣堂数
```

「补了 4 次要催费」在这个模型下,就是**买 4 堂的配套用完了(余额 ≤ 0)**。

之所以不用单纯的 counter 数到 4,是因为 counter 会在这些情况打结,而 ledger 通通接得住:

- 学生预付 8 堂 → 第 4 堂不会误催
- 学生单堂付 → 一样能算
- 学生欠账 → 余额变负数,越欠越明显
- 有人涨价、有人小组价 → 每个学生各自的收费

## 五、出错了怎么办

| 状况 | 做法 |
|---|---|
| 点错出席状态 | 直接到「课程记录」改那一格,`是否扣堂` 和余额会自动重算,旧值存进「修改日志」 |
| 某一堂想特别通融 | 「课程记录」把 `是否扣堂` 手动改成 `否`(会被记录) |
| **整班多点了一堂** | 「今日点名」B1 填那天日期、D1 选班级 → `↩️ 撤销某次点名`。会先列出内容让你确认 |
| 一个学生多算一堂 | 「课程记录」找到那一行,出席状态改成 `我取消(免扣)` |
| 家长说「我孩子那天没上课」 | 翻「修改日志」—— 每次改动的时间、旧值、新值都在 |
| 数字怪怪的 | `📚 补习管理 → 🔄 刷新总览` |
| 表格被弄乱了 | `🔧 初始化 / 修复表格`(可重复执行,**不会删掉你的资料**) |
| **选单「📚 补习管理」不出现** | 见下 |

### 选单不出现怎么办

`onOpen` 是「简单触发器」,在某些环境下不会自动跑(学校/公司的 Google Workspace
政策、浏览器扩充套件、档案是复制来的)。依序试:

1. 试算表按 **F5** 重新整理,等 3 秒(选单是最后才载入的)
2. 还是没有 → Apps Script 里函式下拉选 **`installOpenTrigger`** → **▶ Run**
   这会把它改装成「可安装触发器」,并立刻建一次选单。回试算表 F5。
3. 仍然没有也不影响使用 —— **每个功能都能直接在 Apps Script 里执行**:

   | 要做的事 | 执行这个函式 |
   |---|---|
   | 载入今日点名 | `loadRollcall` |
   | 提交点名 | `submitRollcall` |
   | 刷新总览 | `refreshDashboard` |
   | 查看催费草稿 | `showReminderDrafts` |
   | 记录收款 | `showPaymentDialog` |
   | 撤销某次点名 | `undoRollcall` |
   | 初始化 / 修复表格 | `setupWorkbook` |
   | 立刻备份 | `backupNow` |

## 五之二、备份

三层,建议三个都用:

### 1. Google 内建版本记录(不用设定,已经在跑)

**档案 → 版本记录 → 查看版本记录**。可以看到每一次改动、是谁改的,点一下就还原到那个时间点。
改错、误删几行,用这个救最快。**但档案整个被删掉就救不了。**

### 2. 自动备份到云端硬碟(建议开)

```
📚 补习管理 → 💾 备份 → 开启每周自动备份
```

每星期日晚上会自动复制一整份到 Google 云端硬碟的 **「补习管理备份」** 资料夹,
就算你没打开试算表也照跑。预设保留最近 **8 份**(约两个月),旧的自动丢进垃圾桶
(是垃圾桶,不是永久删除,30 天内还能救)。份数在「设置」表的 `备份保留份数` 改。

要临时备份一份(例如学期结束、或你要大改资料前):

```
📚 补习管理 → 💾 备份 → 立刻备份一份
```

### 3. 离线一份(每学期做一次就好)

**档案 → 下载 → Microsoft Excel (.xlsx)**,存到电脑或随身碟。

前两层都活在 Google 帐号里 —— 万一帐号出事(被盗、被停用),这一份是你唯一的后路。

## 九、从旧 Excel 汇入

如果你本来是用「横轴日期、纵轴学生、1=出席 0=缺席」那种矩阵式 Excel 点名,
`tools/import_excel.py` 可以把它转成能直接贴进新系统的 CSV。

### 要开新档案,还是沿用旧的?

**建议:把旧 Excel 转成 Google Sheet,在同一个档案里装系统。**
旧的分页会原封不动留着当历史参考(初始化只会删掉**完全空白**的工作表)。

1. [drive.google.com](https://drive.google.com) → **新增 → 档案上传** → 选你的 `.xlsx`
2. 上传后**双击**它 → 上方 **「使用 Google 试算表开启」/ "Open with Google Sheets"**
3. ⚠️ **这时还没完** —— 看档名旁边是不是有个绿色的 **`.XLSX`** 标记。
   有的话代表 Google 只是用「Office 相容模式」在编辑那个 xlsx,
   **这个模式不支援 Apps Script,选单里不会有 Extensions**。
   走 **档案 → 另存为 Google 试算表 / File → Save as Google Sheets**,
   会另存成一个新档案(原本的 `.xlsx` 留在 Drive 不会被改)。

   | | 还没转换 | 转换成功 |
   |---|---|---|
   | 档名旁边 | 有 `.XLSX` 标记 | 没有标记 |
   | 选单列 | 没有 Extensions | **有 Extensions** |

4. 在这个新档案照 [一、安装](#一安装约-3-分钟只做一次) 装好程式码
5. 初始化后会**新增** 8 个工作表,你原本的分页照旧
6. 汇入 CSV(见下),再把旧分页改名加个「旧-」前缀或隐藏起来

> Apps Script **只能跑在 Google Sheet 上,不能跑在 .xlsx 上**。
> 要留在 Excel 就得改用 VBA 巨集,而且拿不到 WhatsApp 链接和自动备份。

### 转换 CSV

```bash
pip install openpyxl
python3 tools/import_excel.py 你的旧点名表.xlsx -o out/ \
    --class-fee 初二科学=80/4 --class-fee 高三=70/4
```

`--class-fee 班级=金额/堂数` 可以重复给,没指定的班级用 `--fee` / `--package` 的预设值。

产生 `out/学生.csv`、`out/课程记录.csv`、`out/付款记录.csv`、`out/汇入报告.txt`。
报告最后会列出**每个人汇入后的余额**,贴之前先看一眼对不对。

汇入方式(**不要用 Excel 打开这些 CSV** —— 会把 ISO 日期又转回有问题的地区格式):

1. 在 Google Sheet 点开目标分页(例如「学生」)
2. **档案 → 汇入 → 上传** → 选对应的 CSV
3. 汇入位置:**「在指定储存格取代资料」**,储存格填 **`A1`**
   (CSV 的标题列跟工作表标题一模一样,盖上去刚好对齐)
4. 分隔符号「逗号」,**勾选**「将文字转换为数字、日期和公式」
5. 三个 CSV 各做一次,最后执行 `🔄 刷新总览`

### ⚠️ 它会顺便修好一个你可能没发现的错误

矩阵式 Excel 的日期栏常常**一半是文字、一半是数字,而数字那一半的日和月被对调了**:

| 你输入 | Excel 存成 | 真正意思 |
|---|---|---|
| `19/1/2026` | 文字 `19/1/2026` ✅ | 1月19日 |
| `12/1/2026` | 数字 `46357` = **2026年12月1日** ❌ | 应该是 1月12日 |

原因是 Excel 地区设定为「月/日/年」而你输入「日/月/年」:日期 > 12 号的 Excel
解析不了就留成文字(正确),≤ 12 号的被当成月份吃掉(错误)。

程式预设会把数字那一半的日月对调回来,并在报告里列出每一笔的还原过程。
**验证方法**:还原后同一个班的上课日会集中在固定星期。实际测过的档案:

| 班级 | 修正后落在固定星期 | 不修正 |
|---|---|---|
| 初二科学 | 19/23 | 12/23 |
| 高二补习 | 21/26 | 12/26 |
| 高三 | 18/22 | 10/22 |
| 高一 | 14/15 | 7/15 |

确定旧档日期本来就是对的,加 `--no-swap-fix` 关掉修正。

### 几个汇入时的规则

| 旧档 | 汇入成 | 扣堂 |
|---|---|---|
| `1` = 算钱 | 出席 | ✅ |
| `0` = 不算钱 | 请假(免扣) | ❌ |
| 空白 | **不产生记录** —— 视为当时还没入学或已退出,不是缺席 | — |
| 底色 | 该堂已缴费(见下) | — |
| 工作表名称 | 该班学生的「班级」 | — |

矩阵式点名表里的 `1 / 0` 通常记的是**这堂算不算钱**,不是「有没有出现」——
学生缺席但老师通融不收钱,那格就写 0。所以 `0` 汇入成「请假(免扣)」。

旧档的 `0` 如果是「缺席但照算」,重跑一次并加上 `--zero-charged`。

> 验算方法:随便挑几个学生,数一数他那一列有几个 `1`,应该等于报告里的「已上」。

### ⚠️ 底色 = 已缴费

很多人会把「已经收过钱」的堂数涂上底色(通常是黄色),从第一堂往后连续涂。
程式会**自动侦测档案里最常出现的那个底色**,把涂色的格子数当成该学生的
「已付堂数」,转成一笔付款记录:

| 涂色的格子 | 算不算已缴 | 为什么 |
|---|:--:|---|
| 值是 `1` | ✅ 算 | 缴过的一堂 |
| 值是 `0` | ❌ 不算 | 那堂本来就不收钱。老师涂色时会把整段涂满,中间夹的 `0` 不该算 |
| **整格空白** | ⚠️ 看情况 | **预缴** —— 还没上的课先收了钱 |

**预缴**只有出现在「最后一个涂色的 `1`」**之后**才算。排在前面的表示那笔预缴
已经被后面真正上的课用掉了,只是旧记号还留着 —— 再算一次就重复了。

```
购买堂数 = 涂色且值为 1 的格数 + 有效的预缴记号数
金额RM   = 购买堂数 × 每堂收费
付款日期 = 该学生第一格涂色的日期
```

> **验算:「已缴」一定是配套堂数的整数倍。**
> 涂色的规则是「一期涂满 4 个 `1`」—— 中间遇到 `0` 就往右多移一格,
> 所以每涂一次,黄色里的 `1` 就多 4 个。
>
> 报告会把不是整数倍的人用 ⚠️ 标出来,并算出**上下两个整期的边界日期**
> 让你核对是多涂还是少涂。确认后用 `--paid-override 姓名=堂数` 重跑:
>
> ```bash
> python3 tools/import_excel.py 旧档.xlsx -o out/ \
>     --paid-override 蓝子健=16 --paid-override Moses=12
> ```

这样汇入后的余额就是真的 —— `已缴堂数 − 已上堂数`,谁欠几堂一目了然。

| 情况 | 参数 |
|---|---|
| 自动侦测(预设) | 不用加 |
| 指定颜色 | `--paid-fill FFFF00` |
| 旧档的颜色不代表缴费 | `--paid-fill none` |

档案里如果有不只一种底色,报告会全部列出来并标明用了哪一个 —— 猜错就用
`--paid-fill` 指定。

> 没有底色资料的旧档,汇入后每个人的余额会是一大笔负数(历史全部算欠费)。
> 那种情况建议用 `--history none` 只汇入名单,余额从今天重新开始算。

不想要历史记录,只要学生名单的话:

```bash
python3 tools/import_excel.py 旧点名表.xlsx -o out/ --history none
```
