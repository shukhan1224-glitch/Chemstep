# 线上补习点名 + 收费提醒系统

用 Google Sheet + Apps Script 做的补习管理系统。点名、算堂数、到期提醒缴费,一张试算表搞定。

**设计前提(已跟使用者确认):**

| 项目 | 决定 |
|---|---|
| 计费规则 | 排课就算,**学生自己不来照扣**;生病/比赛可由老师标「请假(免扣)」 |
| 通知方式 | 系统只**生成草稿 + WhatsApp 链接**,不自动送出 |
| 使用者 | 单人使用(老师本人),不需要登入系统 |
| 形态 | Google Sheet + Apps Script |

---

## 一、安装(约 5 分钟,只做一次)

1. 打开 [sheets.new](https://sheets.new) 建一个新的 Google Sheet,取名例如「补习管理」。
2. 选单:**扩充功能 (Extensions) → Apps Script**。
3. 把 `apps-script/` 里的 **5 个 `.gs` 档案**逐一贴进去:
   - 删掉编辑器里预设的 `Code.gs` 内容。
   - 每个档案按左边的 **+ → 指令码 (Script)**,档名照抄(`00_Config`、`01_Setup`、`02_Attendance`、`03_Dashboard`、`04_Reminders`、`05_Triggers`),把对应内容贴上。
   - 档名不含 `.gs` 也没关系,Apps Script 会自动加。
4. 按 **储存 (💾)**。
5. 回到试算表,**重新整理页面**。上方会出现新选单 **📚 补习管理**。
6. 点 **📚 补习管理 → 🔧 初始化 / 修复表格**。第一次会跳授权画面:
   `检阅权限 → 选你的 Google 帐号 → 进阶 → 前往「未验证的应用程式」→ 允许`。
   (这是你自己写的脚本、跑在你自己的档案里,Google 对未上架的脚本一律这样提示。)
7. 看到 ✅ 初始化完成 就好了。

> 时区预设 `Asia/Kuala_Lumpur`。要改的话到 Apps Script 的 ⚙️ 专案设定,或直接改 `appsscript.json`。

## 二、先填两个地方

### 「设置」表

| 设定项目 | 说明 |
|---|---|
| 老师名字 | 讯息的署名 |
| 每期配套堂数 | 一期几堂,预设 `4`(就是你说的「补了4次」) |
| 默认每堂收费RM | 学生表没个别填收费时用这个 |
| 催费门槛(余额≤) | 预设 `0` —— 堂数用完就标红 |
| 预告门槛(余额=) | 预设 `1` —— 剩最后一堂先温馨提示 |
| 催费讯息模板 | 可用变数:`{家长} {学生} {老师} {已扣堂数} {余额} {配套堂数} {金额} {每堂收费}` |
| 预告讯息模板 | 同上 |

### 「学生」表

打上**姓名**,系统会自动配 `学生ID`(S001…)和状态「在读」。其余填一填:

| 栏位 | 备注 |
|---|---|
| 家长称呼 | 讯息开头会用,例如「陈太太」。留空就用「XXX家长」 |
| WhatsApp号码 | `0123456789` 或 `60123456789` 都可以,系统会自动转成 wa.me 格式 |
| 每堂收费RM / 配套堂数 | 留空就用「设置」的预设值(可以每个学生不一样) |
| 状态 | `在读` / `暂停` / `结束`。结束的不会出现在总览和点名表 |

## 三、日常操作

### 点名(每堂课后 10 秒)

```
📚 补习管理 → ✅ 载入今日点名
```

会把所有「在读」学生列出来,**预设全部「出席」**,并显示每个人目前的余额。
你只需要改有状况的那几个,然后:

```
📚 补习管理 → 📥 提交点名
```

提交后系统立刻告诉你:记了几笔、扣几堂、**以及谁的堂数已经用完该催费了**。

> 要补录前几天的课?把点名表 **B1 的日期**改掉再提交就好。
> 同一个学生同一天只会记一笔,重复提交会自动略过。

### 出席状态的规则

| 状态 | 扣堂? | 什么时候用 |
|---|---|---|
| 出席 | ✅ 扣 | 正常上课 |
| 缺席(照算) | ✅ 扣 | 学生自己没来、没提前讲 |
| 请假(免扣) | ❌ 不扣 | 生病、比赛,你批准的 |
| 我取消(免扣) | ❌ 不扣 | 你自己取消的 |
| 公假/停课(免扣) | ❌ 不扣 | 公共假期、考试周 |

规则写在 `00_Config.gs` 的 `CHARGEABLE_BY_STATUS`,要改哪一个算不算钱,改那里就好。

### 记录付款

到「付款记录」表填一行:**学生ID、金额RM、购买堂数**。
姓名、日期、时间戳会自动带出来,总览也会立刻更新。

> 学生付 4 堂的钱 → `购买堂数 = 4`。付 8 堂 → 填 8。系统照样运作,不必改设定。

### 催费

```
📚 补习管理 → 📱 查看催费草稿
```

会跳出视窗,列出所有 🔴 该催费 和 🟡 快用完 的学生,连讯息文案都写好了。
按 **📱 在 WhatsApp 打开** → WhatsApp 会带着文字开起来 → **你再决定要不要送**。

送出后回「总览」勾一下 **已发送**,系统会写进「催费日志」,勾勾会自动跳回(下一期还能再勾)。

「总览」每一行右边也有一颗 📱 发送催费 链接,效果一样。

## 四、余额是怎么算的

```
余额 = 已付堂数 − 已扣堂数
```

「补了 4 次要催费」在这个模型下,就是**买 4 堂的配套用完了(余额 ≤ 0)**。

之所以不用单纯的 counter 数到 4,是因为 counter 会在这些情况打结,而 ledger 通通接得住:

- 学生预付 8 堂 → 第 4 堂不会误催
- 学生单堂付 → 一样能算
- 学生欠账 → 余额变负数,越欠越明显
- 有人涨价、有人小组价 → 每个学生各自的收费

## 五、出错了怎么办

| 状况 | 做法 |
|---|---|
| 点错出席状态 | 直接到「课程记录」改那一格,`是否扣堂` 和余额会自动重算,旧值存进「修改日志」 |
| 某一堂想特别通融 | 「课程记录」把 `是否扣堂` 手动改成 `否`(会被记录) |
| 家长说「我孩子那天没上课」 | 翻「修改日志」—— 每次改动的时间、旧值、新值都在 |
| 数字怪怪的 | `📚 补习管理 → 🔄 刷新总览` |
| 表格被弄乱了 | `🔧 初始化 / 修复表格`(可重复执行,**不会删掉你的资料**) |
| 备份 | Google Sheet 有版本记录(档案 → 版本记录)。重要的话每学期另存一份副本 |

## 六、档案结构

| 档案 | 内容 |
|---|---|
| `00_Config.gs` | 表名、栏位、出席状态与计费规则、共用工具 |
| `01_Setup.gs` | 建立/修复所有工作表、下拉选单、格式 |
| `02_Attendance.gs` | 载入点名、提交点名(含重复防呆) |
| `03_Dashboard.gs` | 余额计算、总览重绘、找出该催费的人 |
| `04_Reminders.gs` | 讯息模板套用、wa.me 链接、草稿视窗 |
| `05_Triggers.gs` | 选单、onEdit 自动化、使用说明 |
| `tests/logic.test.js` | 用假资料验证余额算法与讯息套版 |

工作表:`总览`、`今日点名`、`学生`、`课程记录`、`付款记录`、`设置`、`催费日志`、`修改日志`。

### 测试

改了计费规则(例如把「缺席(照算)」改成免扣)之后,可以跑一次确认没算错:

```bash
node tests/logic.test.js
```

测试涵盖:预付 8 堂不被误催、请假免扣、缺席照算、号码正规化、讯息套版金额、wa.me 链接跳脱。

## 七、还没做、之后可以加

这些是刻意留到 v2 的,现在做只会拖慢你开始用:

- **自动送出讯息**(Telegram Bot 或 WhatsApp Business API)—— 目前是刻意人工按送出
- **每天定时检查**并提醒你「今天有 3 个人该催费」(Apps Script 时间驱动触发器)
- **一个家长两个孩子合并账单**
- **月结报表 / 收入统计**
- **家长自己登入查记录**

先用两个星期,再决定哪一个真的需要。
